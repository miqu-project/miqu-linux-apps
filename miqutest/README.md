# MiquTest 🧪

An interactive component testing sandbox and widget showcase application built for developing, benchmarking, and verifying **`miqutoolkit`** controls.

---

## ✨ Features

- 🧩 **Widget Showcase**: Live interactive tests for buttons, sliders, progress bars, cards, dropdowns, and input fields.
- 🎨 **Theme Verification**: Dynamic color palette inspection and live token reloading.
- 📐 **Layout Engine Sandbox**: Rigorous testing of flexbox, column, row, and absolute geometry constraints.
- ⚡ **Performance Benchmarking**: Stress testing Wayland frame rendering, Cairo damage tracking, and Pango text layout.

---

## 🛠️ Build & Installation

### Prerequisites
- C++20 compiler (`gcc` or `clang`)
- CMake 3.20+
- `miqutoolkit`

### Local Build
```bash
./make.sh
```

### System Installation
To build and install system-wide to `/usr`:
```bash
sudo ./make.sh
```
